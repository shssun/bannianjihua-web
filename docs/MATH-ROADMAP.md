## 2. 人教社官方交互资源清单 —— 最硬的一份「可视化性」背书

人教社为 2019 版配套的**官方交互动画**，等于教材编写方给出的「哪些点值得做成交互」的权威答案。
其选点与我们的技术路线（**单参数滑块 / 参数演示**）**高度一致**：

| 册 | 官方交互资源（共 26 项） |
|---|---|
| 必修一 | 函数的奇偶性 · 指数函数的图象和性质 · 不同函数增长的差异 · 求函数零点的近似值 · 弧度制 · **正弦函数的图象** · **正切函数的图象** · **参数 φ 对 y=sin(x+φ) 的影响** · **参数 ω 对 y=sin(ωx+φ) 的影响** · **参数 A 对 y=Asin(ωx+φ) 的影响** |
| 必修二 | **平面向量的分解** · 球的体积 · 直线网密铺平面 · 长方体的结构 · **不同抽样估计效果的比较** · **频率分布直方图** · 随机数的产生与随机模拟 |
| 选必一 | **空间图形模型** · **用平面截圆锥** · **椭圆与双曲线的定义** · **双曲线的渐近线** · 圆锥曲线的统一定义 |
| 选必二 | 前 n 项和满足某种条件的数列特征 · **切线与割线** · 三次函数的图象与性质 |
| 选必三 | **正态分布** |

**读出来的三条结论**：

1. **三角（必修一 10 项里占 6：弧度制 / 正弦图象 / 正切图象 / φ / ω / A）+ 统计概率（必修二 7 项里占 3）
   + 圆锥曲线（选必一 5 项里占 4）是官方眼里的「交互高价值区」** ——
   与本文推荐顺序 ①③ 一致；三角排第一有官方背书。
2. 官方做了 **`y=Asin(ωx+φ)` 三个参数各一个动画** —— 而我们的 `function-param-lab` 已有 `sin(ωx+φ)`
   场景但**没有单位圆**；官方把「正弦图象」单列，说明**单位圆 ↔ 正弦曲线的联动**是公认的核心直观。
3. 官方**没做**复数、计数原理的交互 —— 不代表不值得做，而是复数/计数原理的交互更适合
   **复平面（几何）**与**树状图/杨辉三角（组合）**这类形态，教材配套资源受形态限制没做。
   对我们反而是**空白机会**（尤其复数的「乘法 = 旋转」是极具冲击力的一拖）。

> 来源：人教社官网「数学交互资源」栏目（`pep.com.cn` 必修/选择性必修各册页面）。

## 3. 引擎分层与成本判据（**成本估算的依据在此，不是拍脑袋**）

### 3.1 现有引擎实测结构

`public/tools/math/function-param-lab/index.html`：**1081 行单文件**，构成如下：

| 部分 | 内容 | 约行数 |
|---|---|---|
| 场景数据 | `SCENARIOS` 数组，12 个场景对象 | ~500（12 场景 × ~40 行） |
| 绘制 | `drawGrid(view)` 坐标轴/网格/刻度 + `drawCurve(scene, view)` 曲线，含断点处理 | ~150 |
| UI | `renderTabs()` 分组标签页 + `renderParams()` 滑块 + 归零按钮 + 读数区 | ~250 |
| 交互 | 主循环、`requestAnimationFrame` 节流、状态 `state` | ~180 |

**单个场景对象的字段**（加场景的全部成本）：
`id / group / label / sub / params[] / fn(x,p) / overlay(h) / readout(p) / conclude(p)`

> ✅ 所以「**加一个 2D 曲线场景 = 写一个约 40~80 行的数据对象**」，无需碰引擎。
> 📌 这是「可复用」这个判断的**实测依据**。

### 3.2 四个成本档（后续估算统一用这套口径）

| 档 | 含义 | 约当量 | 典型 |
|---|---|---|---|
| **数据对象级** | 只往已有 `SCENARIOS` 加对象 | 40~80 行/场景 | 导数场景、不等式场景 |
| **新绘制级** | 复用坐标系 + 滑块 + 读数区（约 400 行可直接搬），**新增一种绘制函数** | 600~1000 行/工具 | 单位圆、复平面、散点图、柱状图 |
| **新引擎级** | 全新渲染管线（3D 投影矩阵、可旋转视角） | 1500 行+ / 工具 | 立体几何 |
| **轻量级** | 非曲线：树状图 / 三角阵列 / 数轴 / 韦恩图 | 300~600 行/工具 | 计数原理、集合逻辑 |

### 3.3 硬约束（沿用 `PLAN-math.md` §10，对全部新工具同样适用）

- ❌ 零第三方绘图库、零 CDN 资源（Desmos / GeoGebra / plotly / echarts / d3 一律不用）
- ❌ 不用 `eval` / `new Function`（CSP 与同源安全）
- ✅ 手写 Canvas 2D；产物天然是一个独立 `index.html`
- ✅ 高 DPI：`devicePixelRatio` 缩放 + `setTransform`
- ⚠️ 断点必须硬做对（`x=0` 处不得画穿屏竖线、渐近线不得跨线连接）

## 4. 逐模块可视化方案

### 4.1 ⭐① 单位圆实验室（`unit-circle-lab`）—— 补三角

**为什么排第一**：三角是必修一**分值最高的一章**；官方交互资源 10 项里 4 项是三角；
而现有工具只有 `sin(ωx+φ)` 的平移读数，**缺「角 → 三角函数值 → 曲线」这条核心链条**。

**覆盖**：必一 第五章 #24~29（6 条）+ 补 3 条增量。

**形态**：**左单位圆 + 右函数曲线，双向联动**（拖圆上点 → 曲线上的点同步走）。

| 场景 | 滑块/拖拽 | 一拖就现形 | 来源 |
|---|---|---|---|
| 单位圆定义 | 拖角 θ | sin/cos/tan 三条线段长度随角变化 | 必一 5.2 |
| 诱导公式「奇变偶不变」 | 拖角 + 选 π/2 的奇偶倍 | 对称点纵/横坐标关系一眼可见 | #28 |
| 正弦曲线从圆上长出来 | 拖角（动画） | 圆周运动 → 正弦曲线留下的轨迹 | **官方「正弦函数的图象」** |
| 对称中心 vs 对称轴 | 拖角度 | 中心 `(kπ,0)` 是点、轴 `x=π/2+kπ` 是竖线 | #26 |
| tan 的渐近线 | 拖角过 π/2 | 曲线断开、值「不存在」 | #27 |
| 和的最值 `sinx+cosx` | 拖 x | 峰值 √2 而非 2（两条虚线对比） | #29 |
| 正弦定理两解 (SSA) | 拖边长 a | 可作三角形个数 0/1/2 跳变 | #25 |

**成本**：新绘制级（中）。**风险点**：单位圆与曲线的**双向联动**是新增交互模式（现有只有单向滑块）。

### 4.2 ⭐② 复数平面实验室（`complex-plane-lab`）—— 补整章空白

**为什么值**：整章空白 + 新高考必考小题 + **可视化冲击力最强**（乘法 = 旋转，一拖就懂，教辅讲十遍不如拖一下）。

**覆盖**：必二 第七章（7.1 概念 / 7.2 四则运算 / 7.3 三角表示）。

| 场景 | 滑块/拖拽 | 一拖就现形 |
|---|---|---|
| 复数的几何意义 | 拖点 z | `|z|`（到原点距离）与 `arg z`（辐角）实时显示 |
| **复数乘法 = 旋转 + 伸缩** ⭐ | 拖 z₁、z₂ | 乘积点 = 模相乘、辐角相加；**特别演示 ×i = 逆时针转 90°** |
| 共轭复数 | 拖点 | 关于实轴**镜像** |
| 复数加法 | 拖两点 | 平行四边形法则（与向量同构） |
| 棣莫弗定理 | 拖 n | `(cosθ+isinθ)ⁿ` 在单位圆上**绕 n 圈** |
| 除法 = 反向旋转 | 拖两点 | `z₁/z₂` 辐角相减 |

**成本**：新绘制级（中偏低）——复平面就是**加了拖点能力的 2D 坐标系**，`drawGrid` 可直接复用。
**风险点**：现有交互是滑块，**拖拽点**是新增输入方式（约 60~100 行）。

### 4.3 ⭐③ 统计与概率实验室（`stats-lab`）—— 一章空白 + 一章薄弱 + 一章空白

**为什么值**：**覆盖面最广的一个**（必二9 + 选必三7 + 选必三8，共 3 章）；选必三每年必有大题；
且统计的可视化性天然极强（拖点看数字变，无需复杂绘图）。

**可拆成 2~3 个工具**（若一次做太大）：

| 子工具 | 覆盖 | 核心场景 |
|---|---|---|
| `distribution-lab` | 必二 10 + 选必三 7 | 二项分布柱状（拖 n、p 看形状从偏斜到对称）· 超几何 vs 二项（N 大时趋近）· 正态（拖 μ、σ）· 分布列/期望方差 · **全概率公式**（新教材新增） |
| `regression-lab` | 选必三 8 | **相关系数 r 对离群点极敏感**（拖一个点飞出 → r 从 0.99 掉到 0.3）· 最小二乘回归线 · **残差**（新教材新增）· 决定系数 · 列联表 χ² 独立性检验 |
| `sample-stats-lab`（可并入） | 必二 9 | 频率分布直方图（拖数据/改分箱）· 平均数/中位数/众数在偏态下的分离 · **百分位数**（新教材新增）· 抽样估计效果对比（官方有） |

**成本**：新绘制级（中）——散点/柱状图比曲线简单，但**要新增「拖点数据集」与「数值面板」**。

### 4.4 ④ 立体几何实验室（`solid-geometry-lab`）—— 两章一并解决，但要 3D

**为什么放第四**：**覆盖两整章**（必二8 + 选必一1），价值极高；但**唯一需要新引擎**，成本最高。
`MATH-TRAPS` 与 `PLAN-math` 都明确标注「立体几何需 3D，与 2D 分模块」。

**覆盖**：必二 第八章 #48~53 + 选必一 第一章（空间向量，全新）。

| 场景 | 交互 | 要点 |
|---|---|---|
| 空间直角坐标系 | 拖点 / 旋转视角 | 点 `(x,y,z)`、投影 |
| 线面垂直判定 | 旋转视角 | 只垂直**一条**不够，须垂直**两条相交线**（#48） |
| 异面直线所成角 | 平移法 | 范围 `(0°,90°]`（#49） |
| **二面角 / 法向量法** ⭐ | 拖半平面 | 二面角的平面角（**新教材新增**）；法向量夹角与二面角的关系 |
| 球的截面 | 拖平面平移 d | `r = √(R²−d²)`（#53） |
| **平面截圆锥** | 拖平面 | 截出圆→椭圆→抛物线→双曲线（**官方有**，圆锥曲线统一定义） |

**成本**：**新引擎级（高）**——需手写正交/透视投影 + 旋转矩阵 + 深度排序。**建议最后做**。

### 4.5 ⑤ 计数原理（`combinatorics-lab`）—— 整章空白，但可视化性偏中

**覆盖**：选必三 第六章（6.1 两个计数原理 / 6.2 排列组合 / 6.3 二项式定理）。

| 场景 | 交互 | 要点 |
|---|---|---|
| 分步乘法 vs 分类加法 | 拖分支数 | 树状图**动态生长**，看计数按乘/加爆炸 |
| 排列 vs 组合 | 拖 n, k | 同一棵树是否需要「顺序」决定除以 `k!` |
| **杨辉三角与二项式系数** | 拖 n | `(a+b)ⁿ` 展开系数就是杨辉三角第 n 行 |
| 二项式定理展开 | 拖 n | 展开式的项与系数高亮对应 |

**成本**：轻量级（中偏低）——树状图/三角阵列布局，无数学绘图。
**说明**：计数本质是**离散计数**，不适合「连续参数看形变」，故排后。

### 4.6 ⑥ 集合与逻辑（`set-logic-lab`）—— 可视化性多「弱」

**覆盖**：必一 第一章 #1~6（其中 3 条「弱」）。

| 场景 | 交互 | 要点 |
|---|---|---|
| `B⊆A` 含参分类 | 拖 m | **`m<2` 时 `B=∅` 也满足 `B⊆A`**（数轴上 B 消失但打 √）——最经典漏解 |
| 充分 / 必要条件 | 拖点 | 小圆 p 含于大圆 q，看「落在 p 必落在 q」 |
| 解集端点开闭 | 拖端点 | 实心 / 空心与严格不等号的对应 |

**成本**：轻量级（低）。**但**：清单里 6 条中仅 1 条「强」，价值有限 → 最后做。

## 5. 推荐推进顺序（含「零新引擎」的顺带收益）

| 序 | 卡片建议 | 内容 | 成本 | 依赖 |
|---|---|---|---|---|
| **T0** | 参数实验室三期：补导数 / 不等式 / 圆锥曲线场景 | 往已有 `function-param-lab` 加 **13 个数据对象**：#73~76 + #80（导数切线/极值/单调/恒成立）、#36 + #38 + #40（基本不等式取等 / 含参二次不等式）、#57 + #58 + #60 + #62 + #63（圆的一般方程 / 直线与圆 / 双曲线 / 椭圆焦点 / 抛物线定义） | **数据对象级（最低）** | 无 —— **与 ① 并行做** |
| **T1** | 新建「单位圆实验室」 | §4.1 的 7 个场景 | 新绘制级（中） | 无 |
| **T2** | 新建「复数平面实验室」 | §4.2 的 6 个场景 | 新绘制级（中偏低） | 无 |
| **T3** | 新建「统计与概率实验室」 | §4.3，可按三个子工具拆 | 新绘制级（中） | 无 |
| **T4** | 新建「立体几何实验室」 | §4.4 | **新引擎级（高）** | 前面都跑顺后再上 |
| T5 | 计数原理 / 集合逻辑 | §4.5 / §4.6 | 轻量级 | 可选 |

**三条排序理由**：

1. **T0 必须并行**：它不新增任何引擎，纯数据对象，**边际成本最低、见效最快**，
   而且它把 `function-param-lab` 从「12 场景」推向「覆盖函数/数列/解几三章的主体」，
   性价比最高，没有理由等。
2. **① ② 先于 ③**：三角与复数各自**一章**且都是「一个引擎内可讲完」；
   ③ 虽然覆盖 3 章但**形态分散**（散点/柱状/分布），一次做完整度风险更高。
   不过若想**最大化章节覆盖率**，③ 的排序可与 ①② 互换。
3. **④ 一定最后**：唯一需要新引擎，且 3D 的交互设计（旋转视角下的拖拽）风险最高，
   应等 2D 方法论打磨成熟后再做。

## 6. 栏目扩展建议（`high-school-math` 集合的学习路径）

**现状**：`path` 仅 2 步 —— ①「看图辨形」（`function-param-lab`）+ ②「（待建）」缺口步。

**约束已核实**（`scripts/check-tools.mjs` L181~228）：

- ✅ **缺口步（无 `toolId`）不进判重集合** → **允许存在多个缺口步**（各带 `todo` 即可）
- ❌ 有 `toolId` 的步骤，**同一路径内不得重复**同一个 `toolId`
- ✅ 缺口步必须有非空 `todo`

→ **所以「栏目」可以扩成一条多级阶梯**，工具上线时**把对应缺口步替换为实体步**即可：

```ts
path: [
  { label: '看图辨形',   note: '拖动参数看图象怎么变：函数与基本初等 / 数列 / 解析几何',
    toolId: 'function-param-lab' },
  { label: '（待建）圆转起来', note: '单位圆 ↔ 三角曲线联动，角的几何意义',
    todo: '待建 unit-circle-lab' },
  { label: '（待建）复数转一圈', note: '复平面上的旋转与伸缩，乘法即旋转',
    todo: '待建 complex-plane-lab' },
  { label: '（待建）数据会说话', note: '散点、相关系数、分布与回归',
    todo: '待建 stats-lab' },
]
```

> ⚠️ **设计权衡**：缺口步太多会让路径显得「空」。建议**同时最多保留 2~3 个缺口步**，
> 工具上线就替换掉 —— 即「阶梯**始终**比已交付能力多一两级」，而不是一次列满。
