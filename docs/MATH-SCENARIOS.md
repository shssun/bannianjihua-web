## 第一节：#13 二次函数 · 定轴动区间

> 定位：**阶段 2 / T-025**。高考「二次函数在给定区间上的最值」分类讨论，**最大丢分点**。

### 1.1 场景配置（完整）

```json
{
  "scenarioId": "quad-range-on-fixed-interval",
  "title": "二次函数在定区间上的最值（定轴动区间）",
  "engine": "graphing-2d",
  "viewport": { "xRange": [-1, 6], "yRange": [-12, 12] },
  "domainFixed": { "xMin": 1, "xMax": 3, "note": "定义域固定 [1,3]；参数 a 不改变定义域" },
  "function": { "expr": "x^2 - 2*a*x + 3", "latex": "y=x^{2}-2ax+3", "plotOn": [1, 3] },
  "parameters": [
    { "name": "a", "label": "对称轴位置 a", "range": [-1, 5], "step": 0.1, "default": 1,
      "presets": [1, 2, 3] }
  ],
  "derived": {
    "axisOfSymmetry": { "x": "a", "draw": "dashed-vertical", "label": "x=a" },
    "vertex": { "x": "a", "y": "3 - a^2" },
    "endpoints": { "f1": "4 - 2*a", "f3": "12 - 6*a" }
  },
  "overlays": [
    { "type": "shaded-band", "on": "xAxis", "from": 1, "to": 3, "label": "定义域 [1,3]" },
    { "type": "dot", "at": "min-source", "color": "green", "label": "最小值取得点" },
    { "type": "dot", "at": "max-source", "color": "orange", "label": "最大值取得点" }
  ]
}
```

**核对要点（可逐项验算）**

| 量 | 表达式 |
|---|---|
| 函数 | `y = x² − 2ax + 3` |
| 定义域 | `[1, 3]`（固定） |
| 对称轴 | `x = a` |
| 顶点 | `(a, 3 − a²)` |
| 左端点值 | `f(1) = 4 − 2a` |
| 右端点值 | `f(3) = 12 − 6a` |

### 1.2 `minVal` 三分支表（a ≤ 1 → 端点1；1 < a < 3 → 顶点；a ≥ 3 → 端点3）

| 分支 | 条件 | 最小值 | 取得点 | 情形说明 |
|---|---|---|---|---|
| ① | `a ≤ 1` | `4 − 2a` | `x = 1` | 区间全在对称轴右侧 → 区间上递减 → 最小值在右端点 |
| ② | `1 < a < 3` | `3 − a²` | `x = a` | 对称轴落在区间内 → 最小值在顶点 |
| ③ | `a ≥ 3` | `12 − 6a` | `x = 3` | 区间全在对称轴左侧 → 区间上递增 → 最小值在左端点 |

**边界连续性校验**（分类不重不漏的证据）

| 临界点 | ① 给值 | ② 给值 | ③ 给值 | 结论 |
|---|---|---|---|---|
| `a = 1` | `4 − 2 = 2` | `3 − 1 = 2` | — | 两支同值，临界可归任一侧 |
| `a = 3` | — | `3 − 9 = −6` | `12 − 18 = −6` | 两支同值，临界可归任一侧 |

### 1.3 `maxVal` 两分支表

| 分支 | 条件 | 最大值 | 取得点 |
|---|---|---|---|
| ④ | `a < 2` | `12 − 6a` | `x = 3` |
| ⑤ | `a ≥ 2` | `4 − 2a` | `x = 1` |

> 依据：`f(1) > f(3)` ⟺ `4 − 2a > 12 − 6a` ⟺ `a > 2`；`a = 2` 时 `f(1) = f(3) = 0`。

**值域**：`[minVal, maxVal]`。

### 1.4 六条断言

| ID | 触发条件 | 同步展示 | 标签文案 |
|---|---|---|---|
| `Q-1` | `a < 1` | 高亮点 `(1, f(1))` 与函数段右端 | 最小值 = `4 − 2a`（端点） |
| `Q-2` | `a = 1` | 对称轴与区间左端点重合 | **临界**：轴过左端点，①与②结果同为 `2` |
| `Q-3` | `1 < a < 3` | 对称轴竖线穿过函数段，顶点落在区间内 | 最小值 = `3 − a²`（顶点） |
| `Q-4` | `a = 3` | 对称轴与区间右端点重合 | **临界**：轴过右端点，②与③结果同为 `−6` |
| `Q-5` | `a > 3` | 高亮点 `(3, f(3))` | 最小值 = `12 − 6a`（端点） |
| `Q-6` | `a = 2` | 两端点值相等 | 最大值**临界**：`f(1) = f(3) = 0` |

> `Q-2` / `Q-4` 为**临界点徽标**，UI 上建议以醒目标记提示「分类边界」。

### 1.5 为什么这个场景值钱

1. **它是高考二次函数的头号丢分点**：不是「不会算」，而是**分类讨论写不全**——
   漏掉某一种对称轴与区间的位置关系，或**分界点判错/漏检验**（把参数求出来后忘记回代检验是否落在该分类的前提里）。
2. **一个滑块就演出了三种情形**：`a` 从 −1 连续拖到 5，对称轴扫过区间左侧 → 区间内 → 区间右侧，
   最小值来源点自动从 `f(1)` 跳到顶点、再跳到 `f(3)`。**动态过程本身就是分类讨论的直观证明**。
3. **临界点可视化 = 讲清"不重不漏"**：`a=1`、`a=3` 处两支给值相同，学生一眼看到"为什么临界可以归任一侧"，
   这正是静态教辅最难讲清的一步。
4. **可与 `T-024` 场景 1（`y=ax²+bx+c`）形成递进**：先用三系数建立抛物线直觉，再引入"区间限制"制造分类讨论，
   是一条完整的认知阶梯。

## 第二节：#18 幂函数 `y = x^α`

> 定位：**阶段 2 / T-025**。幂函数随指数 α 的**定义域/值域断崖式跳变**——静态教辅讲不清的核心点。

### 2.1 场景配置（完整）

```json
{
  "scenarioId": "power-function-alpha-sweep",
  "title": "幂函数 y=x^α 随指数 α 的定义域/值域跳变",
  "engine": "graphing-2d",
  "viewport": { "xRange": [-4, 4], "yRange": [-4, 4] },
  "function": { "expr": "x^alpha" },
  "parameters": [
    { "name": "alpha", "label": "指数 α", "range": [-3, 4], "step": 0.1, "default": 2,
      "presets": [
        { "label": "1/3", "value": 0.3333333333 },
        { "label": "1/2", "value": 0.5 },
        { "label": "2/3", "value": 0.6666666667 },
        { "label": "1",   "value": 1 },
        { "label": "2",   "value": 2 },
        { "label": "3",   "value": 3 },
        { "label": "-1",  "value": -1 },
        { "label": "-2",  "value": -2 }
      ] }
  ],
  "alphaResolve": {
    "rationalApprox": { "maxDenominator": 12, "tolerance": 1e-9,
      "note": "将 α 近似为最简分数 p/q；无法在分母 ≤ 12 内近似则视为无理数 → 定义域仅 x > 0" }
  }
}
```

### 2.2 六行 `domainRule` 判定表

> 约定：α 先近似为**最简分数 `p/q`**（p 为分子、q 为分母）。**分母 q 的奇偶决定定义域是否含负半轴**。

| # | 条件 | 定义域 | 值域 | 奇偶性 | 备注 |
|---|---|---|---|---|---|
| 1 | `α = 0` | `x ≠ 0` | `{1}` | 偶 | `y = 1`（挖原点） |
| 2 | `α = 正整数 n` | `ℝ` | n 奇：`ℝ`；n 偶：`[0, +∞)` | n 奇：奇；n 偶：偶 | 过 `(0,0)`、`(1,1)` |
| 3 | `α = 负整数 n` | `x ≠ 0` | n 奇：`y ≠ 0`；n 偶：`(0, +∞)` | n 奇：奇；n 偶：偶 | 不过原点，两轴为渐近线 |
| 4 | `α = p/q` 最简，**q 奇** | `ℝ` | p 奇：`ℝ`；p 偶：`[0, +∞)` | p、q 均奇：奇；p 偶：偶 | 负半轴存在 |
| 5 | `α = p/q` 最简，**q 偶** | p > 0：`[0, +∞)`；p < 0：`(0, +∞)` | p > 0：`[0, +∞)`；p < 0：`(0, +∞)` | 非奇非偶 | **关键跳变来源** |
| 6 | `α` 无理 | `(0, +∞)` | `(0, +∞)` | 非奇非偶 | 仅第一象限单支 |

### 2.3 六条断言

| ID | 触发（α 跨越） | 同步展示 | 标签文案 |
|---|---|---|---|
| `P-1` | 由正 → `0` → 负 | 过原点的上升支 → 水平线 `y=1`（挖原点）→ 两支渐近双曲线 | 定义域突增 `x ≠ 0`；值域由 `[0,+∞)` 变 `(0,+∞)` |
| `P-2` | `1/2` → `2/3` | `α=1/2` 仅第一象限；`α=2/3` 出现第三象限支 | **★ 定义域从 `[0,+∞)` 突变为 `ℝ`**（q 由偶变奇） |
| `P-3` | `1/3` → `1/2` | 第三象限支消失 | **定义域从 `ℝ` 突变为 `[0,+∞)`**（q 由奇变偶） |
| `P-4` | 跨越 `1` | 第一象限由「上凸、越来越平」（0<α<1）变为「下凸、越来越陡」（α>1）；`α=1` 恰为直线 `y=x` | 定义域/值域不变，仅形态由平缓变陡峭 |
| `P-5` | 跨越 `−1` | 值域由 `(0,+∞)` 扩为 `y ≠ 0`（负半支出现） | 值域：`x⁻²` 的 `(0,+∞)` → `x⁻¹` 的 `y ≠ 0` |
| `P-6` | `α` 为无理数（如 `√2`、`π`） | 仅第一象限单个分支 | 定义域收缩为 `(0,+∞)` |

### 2.4 这个场景的卖点（点明）

- **核心卖点**：`α` 从 `1/2` 连续微调到 `2/3`，**参数只动了 1/6**，但**定义域在 `[0,+∞)` ↔ `ℝ` 之间断崖式跳变**
  （`P-2`），图象凭空多出一整支。**这是纯静态教辅完全讲不清、只有连续滑块能演出来的现象。**
- **反例彩蛋**（可选）：`α = 1/3` 与 `α = 2/6` 形式等价，但定义域不同（前者因已约分 q=3 为奇 → `ℝ`）——
  幂函数最反直觉的认知陷阱，建议做成「陷阱演示」按钮。
- 与 `T-024` 场景 6（`y=x+a/x`）互补：那个讲"对勾"的连续形变，这个讲"定义域离散跳变"，
  一软一硬，覆盖幂函数两类难点。

## 第三节：#22 判别式 Δ 与抛物线和 x 轴的交点个数

> 定位：**阶段 2 / T-025**。二次方程根的个数 ⇔ 抛物线与 x 轴交点个数，`Δ` 的符号决定一切；
> 「`Δ=0` 是一个根还是两个根」「`Δ<0` 是没有根还是没交点」是最经典的混淆。

### 3.1 场景配置（完整）

```json
{
  "scenarioId": "quadratic-discriminant",
  "title": "判别式 Δ 与抛物线和 x 轴的交点个数",
  "engine": "graphing-2d",
  "viewport": { "xRange": [-5, 5], "yRange": [-6, 8] },
  "function": { "expr": "x^2 + b*x + c", "latex": "y=x^{2}+bx+c", "aFixed": 1 },
  "parameters": [
    { "name": "b", "label": "一次项系数 b（决定对称轴位置）", "range": [-4, 4], "step": 0.5, "default": -2,
      "presets": [-2, 0, 2] },
    { "name": "c", "label": "常数项 c（顶点高度 / 纵截距）", "range": [-4, 4], "step": 0.1, "default": 0,
      "presets": [-1, 0, 1, 2] }
  ],
  "derived": {
    "discriminant": "b^2 - 4*c",
    "roots": "x = (-b ± sqrt(b^2 - 4*c)) / 2",
    "vertex": { "x": "-b/2", "y": "c - b^2/4" },
    "axisOfSymmetry": { "x": "-b/2" }
  }
}
```

> 约定 `a = 1` 固定（`a≠0` 是二次函数的前提，见 `T-024` 场景 1 的「a=0 退化」）。此时 `Δ = b² − 4ac = b² − 4c`。

**核对要点（可逐项验算）**

| 量 | 表达式 |
|---|---|
| 函数 | `y = x² + bx + c`（`a = 1` 固定） |
| 判别式 | `Δ = b² − 4c` |
| 对称轴 | `x = −b/2` |
| 顶点 | `(−b/2, c − b²/4)` |
| 与 x 轴交点 | `x = (−b ± √Δ)/2`（`Δ ≥ 0` 时） |
| 顶点纵坐标与 Δ 的关系 | `Δ = −4a·y_顶 = −4·(c − b²/4)`（`y_顶>0 ⟺ Δ<0`） |

### 3.2 `Δ` 三分支表

| 分支 | 条件 | Δ | 与 x 轴交点个数 | 取得点 |
|---|---|---|---|---|
| ① | `c < b²/4` | `Δ > 0` | 2 个不同交点 | `x₁,₂ = (−b ± √Δ)/2` |
| ② | `c = b²/4` | `Δ = 0` | **1 个交点（相切，重根）** | `x = −b/2` |
| ③ | `c > b²/4` | `Δ < 0` | **0 个交点（无实根）** | 无 |

**种子用例**（可直接作初始值）：`b=−2, c=0` → `Δ=4`，两根 `x=0, 2`；`b=0, c=−1` → `Δ=4`，两根 `x=±1`；`b=0, c=1` → `Δ=−4`，无交点。

### 3.3 解析式精确读数规则

- `Δ` **必须**由 `Δ = b² − 4c` **直接算出并显示**（`a` 固定为 1）；**严禁**靠「逐像素采样后数图象穿轴次数」反推交点个数。
- 交点个数 **必须**由 `Δ` 的符号判定：`Δ>0 → 2`、`Δ=0 → 1`、`Δ<0 → 0`。
- 实根（若存在）按求根公式精确给出，保留到与滑块步长匹配的精度。
- 顶点纵坐标 `c − b²/4` 与 `Δ` 一并显示，用作 `Δ` 符号的可视化佐证（顶点在 x 轴上方 ⟺ 无交点）。

### 3.4 临界点徽标

| 触发 | 徽标文案（全文） |
|---|---|
| `Δ = 0`（即 `c = b²/4`） | **临界 · Δ=0**：方程有两个**相等**的实根，抛物线与 x 轴**相切、只有 1 个交点**（不是「两个交点」，也不是「没有根」）。 |
| `Δ` 由正变负 | **临界 · Δ 变号**：图象与 x 轴由「两个交点 → 相切 → 无交点」，实根由「2 个 → 1 个（重根）→ 0 个」。 |
| `Δ < 0` | **Δ<0**：抛物线与 x 轴**无交点**，对应方程**无实根**（注意：是「无实根」，不是「没有根」——复数范围内仍有 2 个根，本工具只讨论实数）。 |

### 3.5 断言列表

| ID | 触发条件 | 断言 |
|---|---|---|
| `D-1` | `Δ > 0` | 画出 **2 个**交点并标注 `x₁、x₂`；读数区显示 `Δ>0` 与两根精确值 |
| `D-2` | `Δ = 0` | **恰好画出 1 个**交点（相切点），**不得**画两个重合点或两个标签；徽标显示「相切 · 重根」 |
| `D-3` | `Δ < 0` | **不画任何**与 x 轴的交点；读数区显示「无实根」而非空值 |
| `D-4` | 任意 | 交点个数由 `Δ` **解析判定**，不得由采样得到 |
| `D-5` | `b = 0` | 对称轴为 y 轴（`x=0`），两根互为相反数 `±√(−c)`（`c<0` 时） |
| `D-6` | 顶点落在 x 轴上 | 顶点与切点**重合**，不得显示成两个不同的点 |

## 第四节：#16 指数函数底数 a 跨过 1

> 定位：**阶段 2 / T-025**。「a=1 也算指数函数吗」——代入即退化成水平线；底数跨过 1 时单调性整条翻转。

### 4.1 场景配置（完整）

```json
{
  "scenarioId": "exp-base-crossing-one",
  "title": "指数函数 y=a^x 的底数 a 跨过 1",
  "engine": "graphing-2d",
  "viewport": { "xRange": [-4, 4], "yRange": [-1, 10], "autoFitNote": "a<1 时曲线在 x<0 迅速抬升，超出可视窗时自动缩放" },
  "function": { "expr": "a^x" },
  "parameters": [
    { "name": "a", "label": "底数 a", "range": [0.1, 4], "step": 0.05, "default": 2,
      "presets": [
        { "label": "0.5", "value": 0.5 },
        { "label": "≈1⁻", "value": 0.95 },
        { "label": "1（临界）", "value": 1 },
        { "label": "≈1⁺", "value": 1.05 },
        { "label": "2", "value": 2 },
        { "label": "e≈2.718", "value": 2.718281828459045 }
      ] }
  ]
}
```

> 滑块范围 `a ∈ [0.1, 4]` 保证 **a=1 能精确取到**（`0.1 + 18×0.05 = 1.0`；并用预设按钮写死 `value: 1` 以免浮点误差）。

### 4.2 三分支表

| 分支 | 条件 | 单调性 | 值域 | 过定点 |
|---|---|---|---|---|
| ① | `0 < a < 1` | 减函数 | `(0, +∞)` | `(0, 1)` |
| ② | `a = 1` | 常函数 `y ≡ 1`（**不是指数函数**） | `{1}` | 整条 `y = 1` |
| ③ | `a > 1` | 增函数 | `(0, +∞)` | `(0, 1)` |

> 规定：指数函数的底数必须 **`a > 0` 且 `a ≠ 1`**。`a=1` 时 `y ≡ 1` 是水平线，不是指数函数图象。

### 4.3 解析式精确读数规则

- `y = aˣ` 直接计算并按像素列采样绘制。
- 值域**恒为 `(0, +∞)`**（`a ≠ 1`），**不随 a 改变**——这是反直觉点，必须写死显示。
- 单调性由「`a` 与 `1` 的大小关系」**直接判定**，不采样。
- `a = 1` 时值域显示为 `{1}`，并注明「不是指数函数」。
- 过定点 `(0, 1)` 恒成立，必须标出。

### 4.4 临界点徽标

| 触发 | 徽标文案（全文） |
|---|---|
| `a = 1` | **临界 · a=1**：规定指数函数的底数必须 **`a>0` 且 `a≠1`**。此时 `y ≡ 1` 是**常函数**，图象为水平线 `y=1`，**不是指数函数**。 |
| `a` 由 `<1` 跨到 `>1` | **临界 · 底数跨 1**：图象由「单调递减」翻转为「单调递增」，且在 `a→1` 时整条曲线塌平为水平线。 |

## 第六节：#24 三角函数的实际平移量是 φ/ω 而不是 φ

> `φ` 步长取 `π/12 ≈ 0.2617993877991494`，保证 `π/6`、`π/3`、`π/2`、`π` 都能由预设**精确**取到。
> `ω` 范围 `[0.25, 4]` 排除 `0`（`ω=0` 不再是正弦型函数）。

### 6.2 关键关系

`sin(ωx + φ) = sin[ω(x + φ/ω)]` ⟹ 相对基准 `y = sin(ωx)`，`φ>0` 时**左移** `φ/ω`，`φ<0` 时右移 `|φ/ω|`。周期 `T = 2π/ω`。

**种子用例**：`ω=2, φ=π/3` → 实际左移 `φ/ω = π/6`（而公式里写的是 `π/3`）。这正是清单 #24 的反例：`sin2x → sin(2x+π/3)` 不是左移 `π/3`，而是左移 `π/6`。

### 6.3 解析式精确读数规则

- **同时**显示两个量：① 公式里的相位 `φ`；② 实际平移量 `φ/ω`（这才是图象真正的位移）。
- 位移用 **π 的分数**显示（如 `φ/ω = π/6 ≈ 0.5236`），并标明方向（`φ>0` 左移、`φ<0` 右移）。
- 周期 `T = 2π/ω` 一并显示。
- 曲线按 `sin(ωx+φ)` 精确采样绘制；基准曲线 `y = sin(ωx)` 以**虚线**叠加对比。
- 预设必须能取到精确的 `π/6`、`π/3`、`π/2`、`π`。

> ⚠️ **待核（呈现约定）**：若实现时把「基准曲线」取成 `y = sin x`（而非 `y = sin(ωx)`），则「平移量」的表述不同（此时可读作「先横向伸缩再平移」的综合结果）。本规格统一以 `y = sin(ωx)` 为基准，实现须与此一致，避免同一数字被两种口径解读。

### 6.4 临界点徽标

| 触发 | 徽标文案（全文） |
|---|---|
| `ω = 1` | **易混点 · ω=1**：此时 `φ/ω = φ`，实际平移量与公式相位数值相等——这正是最容易误推「平移 = φ」的原因；一旦 `ω≠1`，两者就不同。 |
| `φ = 0` | 无平移（`φ/ω = 0`）。 |
| `ω` 改变而 `φ` 不变 | **关键反直觉**：`φ` 没动，实际平移量 `φ/ω` 却随 `ω` 改变——平移由 `ω` 和 `φ` **共同**决定。 |
| `φ/ω` 恰为特殊角 | 突出显示如「**实际左移 `π/6`**」。 |

### 6.5 断言列表

| ID | 触发条件 | 断言 |
|---|---|---|
| `T-1` | 任意 | **同时**显示 `φ` 与 `φ/ω` 两个值，**不得**只显示 `φ` 或把 `φ` 当作平移量 |
| `T-2` | `ω=2, φ=π/3` | 标签必须显示「实际左移 `π/6`」（`=φ/ω`），**不得**显示「左移 `π/3`」 |
| `T-3` | 固定 `φ`、拖动 `ω` | 实际平移量读数随之变化 |
| `T-4` | `ω = 1` | 显示「两者相等，最易误判」徽标 |
| `T-5` | 任意 | 显示周期 `T = 2π/ω`，随 `ω` 变 |

| `T-7` | 任意 | 图象由 `sin(ωx+φ)` 精确绘制，峰值 / 零点位置与解析值一致 |

- `a = 2a/2` 精确给出；`b = √(a² − c²)`（**仅当 `a > c` 时**有定义）。
- `2a ≤ 2c` 时 `b` 显示「**无定义（退化）**」，**严禁**显示 `NaN` 或对负数开方。
- 曲线按标准方程精确绘制。
- 可选验证项：在椭圆上任取动点 `P`，实时显示 `|PF₁| + |PF₂|`，恒等于 `2a`（用作定义的直观佐证）。
- `2a` 略大于 `4` 起 `b` 很小 → 椭圆极扁；`2a` 越小越扁，到 `4` 时压成线段。

### 8.4 临界点徽标

|---|---|
| `2a = 2c`（`=4`） | **临界 · 2a=2c**：动点到两定点的距离之和**恰等于**两定点距离，轨迹**退化为线段 `F₁F₂`**（不含两端之外的延长部分），**不是椭圆**。故椭圆定义必须要求 `2a > |F₁F₂| = 2c`。 |
| `2a < 2c` | **轨迹不存在**：由 `|PF₁| + |PF₂| ≥ |F₁F₂| = 2c` 知不可能，动点集为**空集**。 |
| `2a` 略大于 `2c` | **极扁椭圆**：`b = √(a² − c²) → 0`，椭圆被压得很扁，趋近线段但仍为椭圆。 |

### 8.5 断言列表

| ID | 触发条件 | 断言 |
|---|---|---|
| `L-1` | `2a > 2c` | 画椭圆并显示 `a、b、c` 精确值 |
| `L-2` | `2a = 2c` | **不得画椭圆**，只画实线段 `F₁F₂`（端点 `(−2,0)、(2,0)`），标注「退化为线段」 |
| `L-3` | `2a < 2c` | **清空一切曲线 / 线段**，只保留 `F₁、F₂` 两点与「轨迹不存在」提示 |
| `L-4` | `2a ≤ 2c` | 不得显示 `NaN` / 负数平方根 / 复数 |

| `L-6` | 验证项 | 椭圆上任取点 `P`，`|PF₁| + |PF₂| = 2a` 恒成立 |
