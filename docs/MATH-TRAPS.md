## 怎么用这份清单

每条包含 7 个字段：

| 字段 | 含义 |
|---|---|
| **误区** | 学生**具体会怎么想错**（写成学生的原话式误解，不是「概念不清」这类废话） |
| **正解** | 正确结论，含关键成立条件 |
| **反例** | 一个能瞬间打醒人的**具体反例**（给出具体数字／函数／图形） |
| **可视化性** | 该点能否用「一张图 + 拖参数」揭示，分三级（见下） |
| **图示构想** | 若为强／中：**具体怎么画**（画什么曲线、拖什么参数、参数取哪些关键值、高亮什么） |
| **高考频度** | 是否为高考高频考点（通行认知，非官方统计） |
| **来源** | 人教A版（2019）对应章节 |

**可视化性三级口径：**
- **强** ＝ 单一滑块（拖一个参数）即可自证，一拖就现形；
- **中** ＝ 画图有帮助，但仍需配合文字／代数说明；
- **弱** ＝ 不适合图形化，只能靠文字／代数。
